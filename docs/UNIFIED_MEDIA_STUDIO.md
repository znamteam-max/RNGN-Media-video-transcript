# План объединения RNGN Media Studio

## v0.1 — Download + Transcribe

Одна устанавливаемая Windows-программа вместо двух отдельных утилит.

В одном окне:
1. вставить URL и автоматически определить платформу;
2. получить доступные качества;
3. скачать Premiere-ready MP4, исходный вариант или WAV;
4. выбрать локальный аудио/видеофайл;
5. сделать TXT-транскрипт;
6. сделать SRT;
7. при необходимости конвертировать видео.

## v0.2 — YouTube captions без ручного копирования

Существующий src/youtube.js уже умеет находить caption tracks, отличать manual и auto captions, выбирать язык и разбирать JSON3 / VTT / XML.

Следующий шаг: YouTube URL → Субтитры YouTube → список языков → TXT/SRT.

Если у YouTube есть нормальные исходные субтитры, используем их до Whisper.

## v0.3 — one-click flow

URL → скачать → при необходимости сразу транскрибировать → создать SRT → подготовить MP4 для Premiere.

Принцип: рабочие движки не переписываем без необходимости; объединяем стабильные модули и тестируем каждый слой отдельно.
