# RNGN Media Desktop

Программа для Windows (и macOS): скачивание видео и звука по ссылке, локальная расшифровка речи,
готовые субтитры с сайтов и конвертер видео для монтажа.

## Что умеет

**Скачать по ссылке**
- одна или сразу несколько ссылок, плейлисты; YouTube, VK Видео, Rutube, TikTok, Instagram, X, Дзен, OK, Vimeo, Twitch и ещё 1800 сайтов через `yt-dlp`;
- карточка видео: обложка, длительность, реально доступное качество с размером файла;
- видео сохраняется как MP4 H.264 + AAC (откроется в Premiere), без перекодирования, где это возможно; иначе — перекодирование, на видеокарте NVIDIA при наличии;
- «Только звук» в MP3, M4A или WAV; отрезок по таймкодам для любого сайта;
- «Сразу расшифровать» после скачивания;
- посты и карусели Instagram/X — через `gallery-dl`.

**Субтитры** — готовые дорожки (вручную или автоматические, оригинальный язык) в TXT, SRT и VTT без Whisper.
Если субтитров нет — кнопка «скачать звук и расшифровать».

**Расшифровка** — `faster-whisper`, модели «Быстрая» (large-v3-turbo) и «Точная» (large-v3), режим «микс языков»,
результат TXT / SRT / VTT, таймкоды в тексте по желанию. Считает на видеокарте NVIDIA (CUDA 12 + cuDNN 9),
иначе на процессоре. Перевода нет: текст на языке речи.

**Конвертер** — MP4 для Premiere, H.265, ProRes 422 HQ, смена контейнера 1:1 (MP4/MOV/MKV), звук в WAV/MP3.

**Задания** — очередь: скачивание и расшифровка идут одновременно; у каждого задания отмена, повтор, журнал;
история сохраняется.

**Настройки** — тема (как в системе / светлая / тёмная), папка результатов, ускорение NVIDIA, модели,
вход на сайты через файл cookies, автообновление загрузчика.

## Запуск из исходников (Windows)

```bat
SETUP_WINDOWS.bat
RUN.bat
```

`SETUP_WINDOWS.bat` создаёт `.venv`, ставит зависимости и скачивает инструменты в `desktop/tools`.

Посмотреть интерфейс без Python: открыть `ui/preview.html` через любой локальный веб-сервер
(например, `python -m http.server --directory ui`).

## Проверки

```bat
python -m unittest discover -s tests -t .
```

## Сборка установщика

GitHub Actions: `.github/workflows/desktop-build.yml` (Windows) и `desktop-macos.yml` (macOS).
Релиз публикуется только из ветки `main`. Устройство программы — [`ARCHITECTURE.md`](ARCHITECTURE.md).

## ZNAMBO Transcriber

RNGN Media заменяет ZNAMBO Transcriber: расшифровка, SRT, конвертер видео и ускорение NVIDIA перенесены сюда.
Если на компьютере уже есть модели и библиотеки NVIDIA от ZNAMBO, RNGN Media использует их и не скачивает заново.
История восстановления исходного ядра — [`../docs/TRANSCRIBER_RECOVERY.md`](../docs/TRANSCRIBER_RECOVERY.md).
